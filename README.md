## Лабораторная работа № 4
Модернизация веб-сайта из лабораторной работы № 2 с использованием современных возможностей CSS и основ ООП в JavaScript.
### Что реализовано
- **Flexbox**: использован для вёрстки шапки сайта (`header`), блока преимуществ на главной странице (`index.html`) и блока контактов (`contacts.html`).
- **CSS Grid**: использован для сетки карточек товаров на странице каталога (`catalog.html`).
- **CSS-переменные**: все цвета на сайте заданы через переменные в `:root` (`css/style.css`).
- **CSS-анимация**: добавлена анимация `floatAndGlow` с помощью `@keyframes` для изображения аптечки на главной странице.
- **Методология БЭМ**: классы оформлены по системе «Блок — Элемент — Модификатор».
- **Форма и ООП на JavaScript**: на странице `contacts.html` добавлена форма с полями разных типов (`text`, `tel`, `email`, `select`, `textarea`, `checkbox`) и кнопкой отправки. В `js/script.js` создан класс `OrderForm` с конструктором и методом `printInfo()`, который при отправке формы создаёт объект и выводит введённые данные в консоль браузера.
